# Install Neural Rendering

For the AMD HIP backend, follow the [RDNA2NR installation guide](docs/INSTALLATION.md). Run `Install-RDNA2NR.cmd` from the complete extracted release; it prepares weights from your own supported original model DLL and installs the game integration.

For the retained NVIDIA NGX route, see the [NVIDIA setup section](docs/INSTALLATION.md#nvidia-route). The parent fork's original installation notes are preserved in the source checkout under `docs/upstream/`.
