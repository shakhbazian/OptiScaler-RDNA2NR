# Documentation

OptiScaler-RDNA2NR adds an AMD HIP Neural Rendering backend to OptiScaler. Start with the [Quick Start](../README.md#quick-start), then use the guides below for details.

| Guide | Contents |
| --- | --- |
| [Installation](INSTALLATION.md) | Requirements, GUI installer, updates and removal |
| [Settings](SETTINGS.md) | Backend selection, placement, model controls and comparisons |
| [Model](MODEL.md) | Supported source DLL, local conversion and cache |
| [Compatibility](COMPATIBILITY.md) | GPUs, rendering APIs, game coverage and performance limits |
| [NVIDIA compatibility](NVIDIA.md) | Manual setup of the retained NGX route |
| [Troubleshooting](TROUBLESHOOTING.md) | Inactive NR, missing dependencies, installation errors and reports |
| [Architecture](ARCHITECTURE.md) | The network, executor and game integration |
| [Building](BUILDING.md) | Developer requirements, compilation, packaging and checks |
| [Credits](CREDITS.md) | Parent projects, contributors and licenses |

[Parent-fork notes](upstream/README.md) preserve the inherited design and release history. They describe additional NVIDIA paths and historical experiments; use the guides above to determine what the AMD backend actually supports.
