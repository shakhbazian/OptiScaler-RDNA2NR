# OptiScaler-RDNA2NR 0.1.0-preview.1

First developer preview of the AMD HIP Neural Rendering integration into OptiScaler.

## Install

Download the installer ZIP, extract it completely, and run `Install-RDNA2NR.cmd`. Select the game's executable folder and your original **DLSS 5 Neural Rendering 310.8.0.0** `nvngx_dlssnr.dll`. The installer prepares the model locally and installs the integration.

Requirements: Windows x64 with DirectX 12, a `gfx1030` Radeon, AMD Software: Adrenalin Edition with HIP 6, and the Visual C++ v14 x64 runtime. See [Quick Start](../../README.md#quick-start) and [installation](../INSTALLATION.md).

The ZIP includes the HIP companion and portable model converter. Model DLLs, converted weights and AMD driver libraries are user-supplied. The converted model stays in the per-user cache and can serve several games.

## Included

- The original network with selected INT8 matrix paths and sensitive FP16 stages.
- One-pass D3D12 NR before or after upscaling; D3D11 through the existing w/Dx12 upscaler bridge.
- Style, intensity, structure, tone, skin-mask and temporal controls.
- Backend selection and queue/resource-lifetime handling.
- GUI installation, update, verification and removal, with backups and model-cache reuse.
- Ordinary NVIDIA NGX compatibility inherited from the parent frontend.

## Current limits

RX 6900 XT and Cyberpunk 2077 confirm working NR application. This is a developer preview with substantial inference cost, not a promise of playable frame rates. D3D11 is covered by standalone tests; other games and cards need qualification.

HIP supports ordinary one-pass pre/post placement at 100% working size. Vulkan, multipass, finished-picture processing, frame holding and separate edit upscaling are not implemented for HIP. Experimental NVIDIA hybrid/NVFP4 and RTX 40 MFG-unlock paths are excluded from the standard build.

Use the [settings](../SETTINGS.md), [compatibility](../COMPATIBILITY.md) and [troubleshooting](../TROUBLESHOOTING.md) guides when testing. Include logs and paired screenshots/video with reports; keep model DLLs and weight packages private.
