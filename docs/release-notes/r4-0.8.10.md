# OptiScaler-RDNA2NR r4-0.8.10

Includes updates from [OptiScaler-DLSSNR v0.8.10](https://github.com/wilsjo2/OptiScaler-DLSSNR-PreSR-Multipass/releases/tag/v0.8.10) and selected fixes from [OptiScaler](https://github.com/optiscaler/OptiScaler).

## Changes

- Add NVIDIA's optimized Model B from NR 310.9.16.0, with mixed INT8/FP16 execution and an A/B model selector.
- Fix frozen or repeating frames and incorrect colours in The Witcher 3 DX12.
- Fix NR preparation failures when changing model resolution during play.
- Add optional Edge-aware enlargement and halo suppression for reduced-resolution NR.
- Improve FSR provider/model discovery, preserve saved choices and support additional DX12 FFX runtime folders.
- Improve overlay and swapchain stability, Unicode path handling and NVIDIA NR motion scaling below full resolution.
- Standardize prepared-model filenames and automatically reuse verified older caches.

## Install or update

Close the game, extract the complete installer ZIP and run `Install-RDNA2NR.cmd`.
Select the game's executable folder and an original `nvngx_dlssnr.dll`:

| NR DLL version | Models included |
| --- | --- |
| 310.9.16.0 (recommended) | Models A and B |
| 310.8.0.0 | Model A only |

The installer prepares the models locally and preserves existing settings on updates.
On AMD, Auto selects B when available. The optional FSR 4.0.2c INT8 DLL can be selected in the installer.

See [Quick start](https://github.com/shakhbazian/OptiScaler-RDNA2NR/blob/r4-0.8.10/README.md#quick-start) and [installation](https://github.com/shakhbazian/OptiScaler-RDNA2NR/blob/r4-0.8.10/docs/INSTALLATION.md).
