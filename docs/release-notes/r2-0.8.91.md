# OptiScaler-RDNA2NR r2-0.8.91

Based on wilsjo2's OptiScaler-DLSSNR v0.8.91.

## Changes

- Faster HIP execution: calibrated static INT8 feed-forward and projection paths, folded scales, longer INT32 accumulation, fused handoffs and reused attention workspaces. The original network and its controls are retained; 32-channel QKV and attention stay FP16.
- Adjustable NR model resolution, 25–200%, before or after upscaling. The output frame keeps its dimensions; HIP supports Classic, Matched residual and Lighting + colour composition.
- Defaults: Standard, 75% NR resolution, before upscaling, FSR 3 when available and XeFG when its libraries are present. NR and frame generation are enabled separately in the menu. Existing game INI files are kept on update.
- Fix NR being skipped by the shared D3D12 lifetime tracker when it queries the standard destruction-notification interface.
- The original model source and converted package are unchanged; a verified model cache is reused.

## Install or update

Extract the complete ZIP and run `Install-RDNA2NR.cmd`. Select the game's executable folder and your own original DLSS 5 Neural Rendering **310.8.0.0** DLL. For an existing installation, select the same proxy filename. To use the new defaults with an existing INI, set Standard, 75% and pre-upscale placement in the menu, then select FSR 3 and XeFG.

See [Quick start](../../README.md#quick-start), [settings](../SETTINGS.md) and [compatibility](../COMPATIBILITY.md).

## Checks

The combined executor and scaling path passed standalone D3D12 and D3D11 bridge checks, including resolution and queue changes, temporal history, frame formats and rejected inputs. At unchanged scale, the final execution-only optimizations reproduce the accepted quantized output exactly. Static quantization and reduced model resolution can change the image relative to full FP16 processing.

In paired uninstrumented standalone tests, the complete 1080p NR pipeline averaged about 104 ms versus 133 ms in r1 at 100% model size, and 34 ms versus 40 ms at 50% model size. These are pipeline timings, not game FPS.

A user test in Cyberpunk 2077 on RX 6900 XT reported approximately 45 FPS at 1440p with XeFG frame generation, FSR 3 Performance and NR at 75% before upscaling.
