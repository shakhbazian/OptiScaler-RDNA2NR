# OptiScaler-RDNA2NR r3-0.8.91_fix-1

Hotfix for r3: frame generation's **Active** switch is now enabled by default.
The default route remains FSR 3.0 FG input → XeFG output.

Based on wilsjo2's OptiScaler-DLSSNR v0.8.91. Includes all r3 changes below.

## Changes in r3

- **Fix critical FG instability in Cyberpunk 2077.** Native FSR FG input no longer repeatedly enables and disables the output backend. FSR 3.0 FG input → XeFG output is now the default route.
- **Install with FSR 4 INT8.** Select your FSR 4.0.2c INT8 DLL in the installer. It is copied into the game folder and kept on subsequent updates, so installation no longer depends on the source file's location.
- **Automatic FSR version selection.** FSR 4 is preferred when the loaded runtime provides it, with FSR 3 as the fallback. Saved provider choices are respected.
- **NR enabled by default:** Standard, 75% model resolution, before upscaling.
- **Diagnostic cleanup.** The installer clears diagnostic views and console logging.
- **More flexible updates.** The installer can replace manually changed installation files after confirmation, retaining copies and restoring the previous installation if an update fails.
- **One installation launcher.** Removed duplicate setup entry points and clarified HUD handling in the FG menu and documentation.

## Install or update

Extract the complete ZIP and run `Install-RDNA2NR.cmd`. For an existing installation,
select the same game folder and proxy filename. The installer reuses the verified
model cache and preserves your settings.

Automatic FG settings adopt the corrected default. If you previously saved
**Active** as off, enable it once in OptiScaler's FG menu and save settings.
For the default route, enable native FSR frame generation in the game.

See [Quick start](../../README.md#quick-start) and [installation](../INSTALLATION.md).
