# Parent-fork references

[RDNA2NR documentation](../README.md)

These notes preserve the inherited design and release history of [wilsjo2's OptiScaler-DLSSNR](https://github.com/wilsjo2/OptiScaler-DLSSNR-PreSR-Multipass). They cover NVIDIA-specific features and past experiments. They do not establish HIP support, and the standard RDNA2NR build excludes the experimental hybrid/NVFP4 and RTX 40 MFG-unlock paths.

For the parent project's current instructions, see its [README](https://github.com/wilsjo2/OptiScaler-DLSSNR-PreSR-Multipass/blob/main/README.md), [manual NVIDIA installation guide](https://github.com/wilsjo2/OptiScaler-DLSSNR-PreSR-Multipass/blob/main/INSTALL-DLSSNR.md) and [releases](https://github.com/wilsjo2/OptiScaler-DLSSNR-PreSR-Multipass/releases). The source checkout retains the original notes in this directory for developers; the release package only includes this index.

Use the RDNA2NR [compatibility guide](../COMPATIBILITY.md) and [settings guide](../SETTINGS.md) for the supported AMD path.
